# Glacial v1.0 remediation sequence

G045 closed the three P2 owner decisions, G046 added versioned state lifecycle
evidence plus the mandatory deep-security gate, G047 retired the portable
binary edition, G048 established the source-backed privacy boundary, and G049
added focused one-host installed lifecycle evidence while retaining clean-machine
and final-candidate gaps. This installed-only sequence converts the remaining P1 blockers
in the 2026-07-27 audit into bounded future handoffs. It does not authorize
v1.0.0, reserve work for P3 polish, or permit a handoff to weaken an existing
safety or release gate.
