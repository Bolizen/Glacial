# Contributing to Glacial

Bug reports and feature suggestions are welcome through [GitHub Issues](https://github.com/Bolizen/Glacial/issues/new).

Do not place undisclosed vulnerability details in a public issue. Use the private process in [SECURITY.md](SECURITY.md).

External code contributions are not currently being accepted while contributor licensing terms are being established. Unsolicited code contributions should not be understood as accepted or separately licensed.
